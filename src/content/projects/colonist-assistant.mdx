**Colonist Assistant** is an unofficial Chrome extension for friendly Colonist.io games where everyone has agreed to assistant use. It reads the game state already visible to the player, tracks known cards and honest ranges for unknown hands, estimates each player's position, and recommends one legal next step. Optional autopilot can carry out high-confidence steps after checking that the board still matches the state used to choose them.

The extension combines a <Logo fixed src="typescript" /> **TypeScript** integration layer with a Rust decision engine compiled to WebAssembly. Its Strategist engine evaluates opening placements, builds, trades, robber targets, discards, development-card timing, and other legal actions. All game analysis runs locally in the browser, without a server, ads, tracking, or usage reports.
